1. Gumroad sales → Airtable / Google Sheets

What it does

Pulls GET /v2/sales on a schedule, cleans each sale into one flat row, and upserts by sale_id so a rerun never duplicates a row — and a later refund flips refunded on the existing row instead of inserting a second one. Pages through next_page_key; read-only token; token kept in env, never in the workflow.

Files

  • gumroad-to-airtable.n8n.json — importable workflow (Schedule → HTTP → Code → Airtable upsert), 5 nodes.
  • gumroad_sales_to_csv.py — the same transform as a standalone script (--live or --fixture).
  • sample_gumroad_response.json — 5 sales, deliberately messy: a duplicated sale, a refund, a subscription, mixed-case emails, a missing UTM.
  • sample_sales.csv — output: 4 rows.

The check

Input 5 sales, output 4 rows — the duplicate is dropped, not the refund. Emails lowercased, names trimmed, countries uppercased, price_cents kept alongside price_usd, is_recurring derived from subscription_id.
